# 🦷 Dentwise: AI-Powered Dental Care Assistant

Dentwise is a modern, full-stack dental healthcare platform designed to streamline patient care using artificial intelligence. From automated appointment scheduling to an interactive AI voice assistant, Dentwise simplifies the dental experience for both patients and providers.

## ✨ Features

- **🤖 AI Voice Assistant**: Real-time dental advice and assistance powered by Vapi.
- **📅 Appointment Management**: Easy booking, tracking, and management of dental visits.
- **🔐 Secure Authentication**: Robust user management and authentication via Clerk.
- **📧 Automated Notifications**: Appointment confirmations and reminders sent via Resend.
- **📊 Patient Dashboard**: A comprehensive overview of dental history and upcoming visits.
- **🎨 Premium UI/UX**: A beautiful, responsive interface built with Tailwind CSS and Radix UI.

## 🚀 Tech Stack

- **Framework**: [Next.js 15.5.7](https://nextjs.org/) (App Router, Turbopack)
- **Database**: [PostgreSQL (Neon)](https://neon.tech/) with [Prisma ORM](https://www.prisma.io/)
- **Auth**: [Clerk](https://clerk.com/)
- **AI**: [Vapi AI](https://vapi.ai/)
- **Emails**: [Resend](https://resend.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/), [Lucide Icons](https://lucide.dev/)

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+
- npm / yarn / pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/arghya0003/Dentwise.git
   cd dentwise
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up your environment variables (see `.env.example`).

4. Run the development server:
   ```bash
   npm run dev
   ```

## 📦 Deployment

This project is optimized for deployment on **Vercel**. Ensure all production environment variables are configured in the Vercel dashboard.
